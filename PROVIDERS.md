# Providers

These adapters use Node 22's `fetch`, `FormData` and `Blob`; no provider SDK is required. Accounts, upstream credits, provider limits and data handling terms still apply. API calls are made only when parsing is requested. This implementation has been compiled and inspected against the primary sources below; live paid-provider behavior has not been verified.

`builtInProviders()` registers ten hosted adapters. A configured `DOCLING_ENDPOINT` adds Docling Serve as an eleventh. Optional Python local parsers are described in the README and can be registered separately.

| ID | Environment credentials/configuration | Adapter inputs | Structured capabilities |
| --- | --- | --- | --- |
| `mistral` | `MISTRAL_API_KEY` | PDF, DOCX, PPTX, PNG, JPEG, WebP; bytes or HTTPS URL | Markdown pages, typed blocks, tables, images, inferred visual descriptions and supplied coordinates |
| `openai` | `OPENAI_API_KEY` | PDF, PNG, JPEG, WebP, GIF; bytes or HTTPS URL | Inferred text, tables, image/chart/diagram descriptions and equations |
| `anthropic` | `ANTHROPIC_API_KEY` | PDF, PNG, JPEG, WebP, GIF; bytes or HTTPS URL | Inferred text, tables, image/chart/diagram descriptions and equations |
| `gemini` | `GEMINI_API_KEY` or `GOOGLE_API_KEY` | PDF, PNG, JPEG, WebP bytes | Inferred text, tables, image/chart/diagram descriptions and equations |
| `firecrawl` | `FIRECRAWL_API_KEY` | PDF, Office/OpenDocument, HTML, CSV, RTF, EPUB; bytes or HTTPS URL | Markdown; typed layout items/pages when supplied |
| `llamaparse` | `LLAMA_CLOUD_API_KEY` | PDF, DOCX, PPTX, XLSX, HTML, CSV, plain text, PNG, JPEG, WebP bytes | Markdown pages, typed items, tables and image captions |

Format lists are deliberately limited to what each adapter sends. A provider may support more formats through a different workflow. Visual model adapters require PDF or image inputs; convert Office files first or choose an Office-capable parser. Capability flags describe extraction support, not a guarantee that every input yields every feature.

## Credentials and endpoint trust

Keep provider credentials in your server process. `keysFromEnv()` reads the variables above; `providerKeys` supplies the same keys by provider ID for in-process use or server-authorized BYOK. The gateway's access keys authenticate your users and do not replace upstream provider credentials.

Endpoint variables are trusted deployment configuration, captured by `builtInProviders(env)`. They must be HTTPS URLs without user information, query strings or fragments. `AZURE_DOCUMENT_INTELLIGENCE_ENDPOINT` is the resource root, for example `https://YOUR-RESOURCE.cognitiveservices.azure.com`. `DOCLING_ENDPOINT` is the root of your Docling Serve deployment. `UNSTRUCTURED_API_URL` is the complete Partition endpoint; its default is `https://api.unstructuredapp.io/general/v0/general`. Requests cannot override endpoints, authentication, document sources, callbacks or transport settings through provider options. Redirects are rejected.

## API behavior and allowed options

- **Mistral:** `POST https://api.mistral.ai/v1/ocr`, bearer key. Document bytes use a document data URL; images use an image URL/data URL. The adapter maps the provider's zero-based page index to a one-based source page number. Allowed options: `model`, `pages`, `table_format`, `image_limit`, `image_min_size`, `extract_header`, `extract_footer`. Default model: `mistral-ocr-latest`. Structural blocks retain pixel boxes. Requested visual features enable a fixed JSON schema for bounding-box annotations; descriptions are inferred. Sources: [OCR API](https://docs.mistral.ai/api/endpoint/ocr), [OCR inputs and outputs](https://docs.mistral.ai/studio/document-processing/basic_ocr), [annotations](https://docs.mistral.ai/studio/document-processing/annotations), [block schema](https://github.com/mistralai/client-ts/blob/main/docs/models/components/block.md).
- **OpenAI:** `POST https://api.openai.com/v1/responses`, bearer key, `store: false`. PDF inputs use `input_file`; images use `input_image`. Allowed options: `model`, `max_output_tokens`. Default: `gpt-4.1`. The adapter requests extraction JSON and rejects incomplete responses. Source: [File inputs](https://developers.openai.com/api/docs/guides/file-inputs).
- **Anthropic:** `POST https://api.anthropic.com/v1/messages`, `x-api-key`, API version `2023-06-01`. URL or base64 document/image sources. Allowed options: `model`, `max_tokens`. Default: `claude-sonnet-4-6`. Source: [Messages API](https://platform.claude.com/docs/en/api/http/messages), [PDF support](https://platform.claude.com/docs/en/build-with-claude/pdf-support).
- **Gemini:** `POST https://generativelanguage.googleapis.com/v1beta/models/{model}:generateContent`, `x-goog-api-key`, inline base64 media. Allowed options: `model`, `maxOutputTokens`. Default: `gemini-3.8-flash`. Public URL fetching and Files API uploads are outside this adapter. Source: [File input methods](https://ai.google.dev/gemini-api/docs/generate-content/file-input-methods).
- **Firecrawl:** bytes use multipart `POST https://api.firecrawl.dev/v2/parse` with `file` and JSON `options`; URLs use `POST /v2/scrape`. Bearer key. Allowed options: `onlyMainContent`, `removeBase64Images`, `zeroDataRetention`. Markdown is always requested. Source: [Parse API](https://docs.firecrawl.dev/api-reference/endpoint/parse), [supported formats](https://docs.firecrawl.dev/api-reference/endpoint/parse-formats). The adapter retains raw layout boxes in metadata because their unit is not normalized here. Bare image uploads are not advertised by this adapter.
- **LlamaParse:** uploads to `POST https://api.cloud.llamaindex.ai/api/v1/beta/files` with `purpose=parse`, starts `POST /api/v2/parse`, polls `GET /api/v2/parse/{id}?expand=markdown,items`; bearer key. Poll status is `job.status`. Allowed options: `tier`, `version`; defaults `agentic`, `latest`. Older `fast` versions before `2026-06-15` cannot supply the markdown this adapter requests. Item bounding boxes are points. Sources: [getting started](https://developers.llamaindex.ai/llamaparse/parse/getting_started/), [response format](https://developers.llamaindex.ai/llamaparse/parse/guides/response-format/), [retrieving results](https://developers.llamaindex.ai/llamaparse/parse/guides/retrieving-results/).
- **Unstructured:** multipart Partition request with `files`, `unstructured-api-key`, JSON output. Allowed options: `strategy`, `languages`; default strategy `hi_res`. Image requests enable `extract_image_block_types=Image`. Source: [Partition POST](https://docs.unstructured.io/api-reference/api-services/post-requests), [parameters](https://docs.unstructured.io/api-reference/api-services/api-parameters). Element coordinates stay in metadata without an assumed unit.
- **Reducto:** bytes upload to `POST https://platform.reducto.ai/upload`; URL or uploaded handle goes to `POST /parse`, bearer key. Chunking is disabled upstream so the gateway owns chunks. Allowed options: `ocr_system`, `extraction_mode`. Figure summaries and advanced chart processing follow requested features and may change upstream cost. Source pages prefer `bbox.original_page`; boxes use provider-documented normalized coordinates. Sources: [upload](https://docs.reducto.ai/api-reference/upload), [parse](https://docs.reducto.ai/api-reference/parse), [response format](https://docs.reducto.ai/parse/response-format).
- **Azure:** `prebuilt-layout:analyze`, API version `2024-11-30`, `Ocp-Apim-Subscription-Key`; polls the supplied operation URL only after checking the configured origin and expected path. Allowed options: `pages`, `locale`. Equations request the `formulas` feature. Table cells retain row/column metadata. Figure downloads and synthetic descriptions are not enabled. Sources: [Analyze Document](https://learn.microsoft.com/en-us/rest/api/aiservices/document-models/analyze-document?view=rest-aiservices-v4.0%20(2024-11-30)), [layout model](https://learn.microsoft.com/en-us/azure/ai-services/document-intelligence/prebuilt/layout?view=doc-intel-4.0.0).
- **Datalab:** multipart `POST https://www.datalab.to/api/v1/convert`, then `GET /api/v1/convert/{request_id}`, `X-API-Key`. The older `/marker` route is deprecated. Allowed options: `mode`, `page_range`, `max_pages`, `exact_transcription`; default mode `balanced`. Chart requests enable `chart_understanding`. Markdown comes as one unnumbered container; the adapter does not infer page boundaries from prose. Fenced synthetic captions become inferred image blocks. Source: [official OpenAPI schema](https://www.datalab.to/openapi.json), [API documentation](https://www.datalab.to/docs).
- **Docling Serve:** your HTTPS deployment's `POST /v1/convert/source` or multipart `/v1/convert/file`, optional `X-Api-Key`. Requests markdown and JSON; body references establish reading order. Allowed options: `do_ocr`, `force_ocr`, `ocr_lang`, `table_mode`. Sources: [Serve usage](https://github.com/docling-project/docling-serve/blob/main/docs/usage.md), [API implementation](https://github.com/docling-project/docling-serve/blob/main/docling_serve/app.py). Service/model installation is separate. Picture blocks are retained; synthetic picture descriptions require the deployment's own configuration.

## Provenance, limits and upstream jobs

Model-based extraction is probabilistic. OpenAI, Claude and Gemini output blocks are all marked `inferred`; they do not receive invented page numbers or coordinates. Captions inferred by other parsers are marked where their response identifies them. A gateway citation anchors the returned extraction text and its offsets; it does not independently verify the document or model's factual claims.

Some APIs return only markdown, or omit page metadata. Those results retain an unnumbered text container. Tables/images are typed only where the API returns structured content or identified captions. Use `includeRaw: true` to inspect provider-native metadata. No adapter fetches referenced image URLs. External result-download URLs from Datalab/Reducto currently fail explicitly instead of fetching arbitrary returned destinations; use smaller inputs that return inline results.

All network requests and poll delays receive the operation's abort signal. Responses are bounded to 32 MiB; async job polling stops after 180 attempts or the earlier gateway deadline. Aborting the HTTP request does not cancel a job already accepted upstream and may not prevent charges. LlamaParse/Reducto uploads are not automatically deleted; apply the upstream account's retention policy. Provider model availability, input limits and account entitlements can change; override the documented model option with an available vision-capable model when needed.
